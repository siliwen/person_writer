# 产品需求说明

> 2026-08-05 更新：MVP1 当前事实源以 `01_requirements_需求/feature_roadmap_mvp.md` 为准。MVP1 已收窄为 Demo User + 个人风格库写作闭环；真实注册、组织、余额和套餐能力后移到后续版本。

## 用户角色

| 角色 | 需求 |
|---|---|
| 普通写作者 | 用自己的风格快速生成文章、散文、诗歌，减少起稿成本 |
| 小说作者 | 维护人物、世界观、章节计划，按章节生成和改写 |
| 自媒体作者 | 保持固定表达风格，快速生成标题、正文、开头和结尾 |
| 运营人员 | 审核内容、处理投诉、管理套餐、追踪成本和用户反馈 |
| 管理员 | 配置模型、价格、限流、审核策略和故障回退 |

## MVP 范围

首版必须包含：

- 账号登录、用户空间和基础租户隔离。
- 风格素材上传：支持粘贴文本和上传 `.txt/.md/.docx`。
- 素材解析：按作品、章节、段落入库。
- 风格档案：自动抽取语气、句式、节奏、意象、结构偏好、禁用表达。
- 写作任务：文章、散文、诗歌、小说章节四类模板。
- 生成链路：需求澄清、大纲、初稿、风格审校、重写。
- 编辑器：用户可直接修改生成稿，保存版本，支持选中段落局部重写。
- 额度系统：任务预估、额度冻结、成功扣减、失败释放。
- 内容安全：输入审核和输出审核。
- 删除与导出：用户可删除素材、导出作品。

首版可以延后：

- 多人协作空间。
- 小程序原生端。
- 复杂排版出版。
- 每个用户独立微调模型。
- 自动投稿到第三方平台。
- 插画、封面、音频等多模态内容。
- 名家风格库、创作社区和版权水印。

## 核心用户流程

1. 用户注册并选择套餐。
2. 上传个人文章素材，确认拥有合法权利。
3. 系统生成风格档案，用户可以手工调整。
4. 用户选择文体，填写主题、字数、语气、目标读者和限制。
5. 系统先生成大纲或创作计划。
6. 用户确认后生成正文。
7. 系统做风格一致性审校和合规审核。
8. 用户编辑、重写、保存版本或导出。

## 文体增强能力

小说任务可逐步支持世界观设定、人物卡、章节目标、前文摘要、连载一致性约束和多角色对话约束。

散文任务可支持意象发散和情感基调迁移。诗歌任务可支持韵脚建议、断句节奏和格律检查。这些能力可放在 MVP 后的增强版本中，不阻塞首发闭环。

## 关键业务规则

- 风格素材必须属于当前用户或当前租户，检索必须强制带 `tenant_id`。
- 用户未授权的数据不得进入训练集。
- 模型调用密钥只保存在服务端。
- 每次生成必须记录模型 ID、Prompt 版本、素材 ID、token、耗时、成本和审核结果。
- 对长篇小说任务按章节异步执行，不能占用同步 HTTP 请求。
- 失败任务不能直接扣费，必须根据失败原因释放或部分结算。
