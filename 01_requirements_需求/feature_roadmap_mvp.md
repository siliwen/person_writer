# 功能清单与 MVP 分期

更新日期：2026-08-05

## 产品定位

这是面向个人作者、作家协会、写作组织和机构的个人风格写作 SaaS。

平台核心价值：

1. 用户上传多篇自己风格相近的作品。
2. 系统自动分析这些作品的写作风格。
3. 系统输出风格分析结果，用户确认、修改并给这个风格命名。
4. 风格确认后保存到用户个人风格库。
5. 用户写作时从自己的风格库选择一个风格，输入主题和要求。
6. 系统调用千问或后续其他模型，按照选定风格生成文章。
7. 用户可以按自然段提出修改意见，系统只重写指定自然段。

## 账号与组织模型

### MVP1 账号范围

> 2026-08-05 最新决定：MVP1 不做真实个人注册/登录，先使用固定 Demo User 打通个人风格写作闭环。真实个人注册/登录与组织能力后移；本文中旧的“个人注册/登录实现”描述以本段为准。

MVP1 只正式实现个人账号。

## 全量功能清单

### A. 账号

- 个人注册。
- 个人登录。
- 当前用户资料。
- 用户自己的作品库。
- 用户自己的风格库。
- 组织注册接口预留，但 MVP1 不做完整组织 UI 和组织管理。

### B. 作品上传与素材管理

- 粘贴文本。
- 上传 `.txt/.md/.docx`。
- 一次上传多篇风格相近的作品。
- 作品标题、文体、标签。
- 作品解析：自然段、字数、来源文件。
- 作品列表。
- 作品删除。
- 同一批作品可以组成一次“风格分析任务”。

### C. 风格分析与确认

- 用户选择多篇作品发起风格分析。
- 系统调用 AI 分析作品风格。
- 分析结果包括：
  - 风格摘要
  - 适用文体
  - 语气特点
  - 句式特点
  - 节奏特点
  - 常用意象/材料
  - 结构偏好
  - 开头方式
  - 结尾方式
  - 应避免的表达
  - AI 写作时的提示规则
- 分析完成后进入“待用户确认”状态。
- 用户可以编辑分析结果。
- 用户必须给风格命名。
- 用户确认后，风格保存到个人风格库。
- 未确认的风格不能用于正式写作。

### D. 个人风格库

- 查看已保存风格。
- 查看风格详情。
- 编辑风格。
- 删除风格。
- 标记默认风格。
- 写作时从风格库选择一个风格。

### E. 风格写作

- 用户选择文体。
- 用户选择已确认的风格。
- 用户输入主题。
- 用户输入字数/行数。
- 用户输入目标读者。
- 用户输入必须包含/必须避免。
- 系统调用千问生成文章。
- 生成结果按自然段结构化保存。
- MVP1 默认使用 `style_prompt_only + Style Profile`。
- RAG 不作为 MVP1 默认路径。

### F. 段落级修改

- 生成文章后按自然段展示。
- 用户选择某个自然段。
- 用户输入自然语言修改意见。
- 系统只重写该自然段。
- 未选择的段落保持不变。
- 保存段落修改历史。
- 保存文档版本。

### G. 编辑与导出

- 在线富文本编辑。
- 保存草稿。
- 文档版本历史。
- 回滚版本。
- MVP1 可先支持 Markdown/纯文本导出。
- Word/PDF 导出放到 MVP2。

### H. 模型与任务

- 接入千问。
- 预留其他模型供应商接口。
- 写作任务状态：
  - pending
  - analyzing_style
  - waiting_user_confirmation
  - generating
  - rewriting_paragraph
  - completed
  - failed
- 记录模型、prompt 版本、输入输出 token、耗时。
- MVP1 记录 token 和成本，但不做余额扣费。

## MVP1 范围

MVP1 目标：打通个人用户的核心写作闭环。

闭环如下：

个人注册/登录 → 上传多篇相似作品 → AI 风格分析 → 用户确认并命名风格 → 保存到个人风格库 → 选择风格输入主题 → AI 生成文章 → 按自然段修改。

### MVP1 必须实现

#### 1. 个人账号

- 个人注册。
- 个人登录。
- 当前用户资料。
- 用户数据隔离。

#### 2. 组织接口预留

- 后端预留 Organization、Membership 相关模型或接口边界。
- 前端可以不做组织注册入口。
- 不做组织子账号。
- 不做组织余额共享。

#### 3. 作品上传

- 支持粘贴文本。
- 支持 `.txt/.md/.docx` 上传。
- 支持一次上传多篇作品。
- 支持把多篇作品组成一个风格分析批次。
- 自动解析自然段。
- 保存作品和段落。

#### 4. 风格分析

- 用户从作品库选择多篇作品。
- 发起风格分析任务。
- 系统调用千问分析风格。
- 输出结构化 Style Profile 草案。
- 风格草案状态为 `draft_pending_confirmation`。

#### 5. 用户确认风格

- 用户查看风格分析结果。
- 用户可以编辑风格分析结果。
- 用户必须输入风格名称。
- 用户点击确认后保存风格。
- 已确认风格状态为 `active`。
- active 风格进入用户个人风格库。

#### 6. 风格库

- 用户查看自己的风格列表。
- 用户选择某个风格查看详情。
- 用户编辑已保存风格。
- 用户删除风格。
- 用户在写作任务中选择某个 active 风格。

#### 7. 风格写作

- 支持 7 个文体：
  - 散文
  - 故事
  - 小说
  - 剧本
  - 诗歌
  - 杂文
  - 随笔
- 用户选择风格、文体、主题和要求。
- 系统调用千问生成正文。
- 正文按自然段保存。
- 生成历史可查看。

#### 8. 段落级修改

- 用户选择自然段。
- 用户输入修改意见。
- 系统基于原文上下文和选定风格重写该段。
- 保存新段落版本。
- 文档生成一个新版本。

### MVP1 不做

- 余额体系。
- 真实支付。
- 组织正式注册流程。
- 组织子账号管理。
- 组织余额共享。
- 套餐。
- 发票。
- 复杂组织权限。
- 多人协作。
- LoRA/微调。
- RAG 默认生成。
- 风格市场。
- 自动投稿。
- Word/PDF 高级导出。

## MVP2 范围

MVP2 目标：补组织商业化能力和更完整的生产能力。

### MVP2 实现

#### 1. 组织能力

- 组织注册。
- 组织管理员创建/邀请子账号。
- 子账号登录。
- 子账号共享组织余额。
- 管理员禁用/启用子账号。
- 成员用量统计。
- 成员额度上限。
- 批量导入子账号。

#### 2. 余额与支付

- 个人余额。
- 组织余额。
- 在线充值。
- 支付宝/微信支付。
- 套餐。
- 订单记录。
- 发票信息。
- 任务前预估 token。
- 任务执行中冻结额度。
- 成功扣费。
- 失败释放额度。

#### 3. 风格增强

- 多个 Style Profile 版本对比。
- 按文体分别生成风格档案。
- 用户反馈反向更新 Style Profile。
- 风格质量评分。
- 文章/散文类 RAG 实验开关。

#### 4. 长文与复杂文体

- 小说人物卡。
- 小说世界观。
- 章节大纲。
- 剧本角色表。
- 剧本场景表。
- 长文分章节异步生成。
- 前文摘要和一致性检查。

#### 5. 编辑增强

- 文档级版本对比。
- 批注。
- 段落改写建议。
- 一键降低 AI 味。
- Word 导出。
- PDF 导出。

#### 6. 运维与风控

- 更完整的内容安全审核。
- 复制风险检测。
- 模型供应商切换。
- 失败自动重试。
- 成本看板。
- 告警。

## MVP3 或更后

- Personal LoRA/微调。
- 风格授权市场。
- 作协/机构专属私有化部署。
- 多人实时协同编辑。
- 自动投稿到第三方平台。
- 图文混排、封面、插图、多模态创作。
- 版权水印和对外发布链路。

## 当前实现需要调整

当前已搭建的页面只是技术骨架，不是最终 MVP1 页面。

下一轮开发应重构为以下信息架构：

1. 注册/登录。
2. 工作台：作品数量、风格数量、最近写作任务。
3. 作品库：上传多篇作品、查看解析结果。
4. 风格分析：选择多篇作品发起分析。
5. 风格确认：编辑分析结果、输入风格名称、确认保存。
6. 风格库：查看和管理已确认风格。
7. 新建写作：选择文体、选择风格、输入主题。
8. 编辑器：按自然段修改。
9. 组织入口：MVP1 只显示“即将支持”或隐藏，仅后端预留。
