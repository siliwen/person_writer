# 产品体验设计

## 信息架构

首版 Web 应用建议包含以下主导航：

| 页面 | 作用 |
|---|---|
| 工作台 | 查看最近作品、额度、待处理任务和常用入口 |
| 风格库 | 管理上传素材、风格档案和文体档案 |
| 新建写作 | 创建文章、小说、散文、诗歌任务 |
| 作品库 | 查看生成作品、版本、导出记录 |
| 账户与套餐 | 查看额度、订单、发票、套餐权益 |
| 设置 | 隐私、删除导出、模型偏好、通知 |

## 核心界面

首版应弱化“聊天机器人”感，强化专业写作软件体验。用户进入产品后看到的是工作台、风格库和编辑器，而不是一个孤立聊天框。

### 风格库

风格库不是文件网盘，而是“个人写作风格资产”管理页面。每个风格档案应显示：

- 档案名称。
- 适用文体：文章、小说、散文、诗歌。
- 素材数量和总字数。
- 最近更新日期。
- 风格摘要。
- 用户手工规则：必须保留、尽量避免、禁用表达。
- 是否允许用于后续个性化训练。

### 新建写作

新建任务表单建议采用分步式：

1. 选择文体。
2. 选择风格档案。
3. 填写主题、目标读者、字数、表达限制。
4. 选择生成强度：保守、均衡、发散。
5. 预估额度消耗并确认。

小说任务需要额外字段：

- 世界观设定。
- 人物卡。
- 章节目标。
- 前文摘要。
- 连载一致性约束。

### 编辑器

编辑器建议采用 TipTap 或 Lexical。首版必须支持：

- 标题、正文、段落。
- 左侧大纲或章节导航。
- 右侧风格评分、修改建议、召回素材。
- 版本历史。
- 一键重写选中段落。
- 局部指令：更紧凑、更克制、增加环境描写、降低 AI 味、增强人物语气。
- 导出 Markdown、Word 或纯文本。

## 状态提示

长文生成不可只显示转圈，应显示明确阶段：

- 正在理解需求。
- 正在检索个人风格素材。
- 正在生成大纲。
- 正在生成第 N 段或第 N 章。
- 正在进行风格审校。
- 正在进行内容安全审核。
- 已完成或需要人工处理。
