# 测试与评估方案

## 测试目标

验证两个问题：

1. 个人风格写作是否明显优于通用大模型直接生成。
2. SaaS 系统是否能稳定、可计费、可审计地完成公网生成任务。

## 离线效果评测

建立 30～50 个真实任务，覆盖：

- 文章：观点文、经验文、说明文。
- 散文：抒情、叙事、观察。
- 诗歌：现代诗、短诗、组诗。
- 小说：人物出场、冲突推进、场景描写、章节续写。

MVP 评测集的具体设计、任务字段、对照组和通过门槛见 `D:\AI_talk\personal_writing_agent_saas\06_testing_测试方案\mvp_eval_set_design.md`。

每个任务至少对比：

- 通用模型直接生成。
- 通用模型 + 用户素材全文提示。
- 结构化风格档案 + RAG。
- 不同模型供应商输出。

## 评分维度

| 维度 | 说明 |
|---|---|
| 风格相似度 | 是否接近用户本人表达习惯 |
| 任务完成度 | 是否满足主题、字数、结构和限制 |
| 可读性 | 是否自然、清晰、有节奏 |
| 原创性 | 是否避免模板化和第三方作者污染 |
| 可修改成本 | 用户需要改多少才能使用 |
| 安全合规 | 是否命中违规、侵权或隐私风险 |
| 成本 | token、重试、耗时和模型费用 |

## 工程测试

必须覆盖：

- 租户隔离测试：A 用户不能检索到 B 用户素材。
- 额度账本测试：冻结、结算、释放、退款、重复回调。
- 任务恢复测试：模型超时、队列失败、进程重启后可继续。
- 内容审核测试：输入命中、输出命中、申诉流程。
- 删除导出测试：素材删除后向量和派生数据进入删除流程。
- 并发测试：多用户同时发起长文任务。
- 成本记录测试：每次模型调用能追踪实际消耗。

## 上线门槛

首发前必须达到：

- 盲测中个人风格方案稳定优于通用直出。
- 核心任务成功率达到可接受水平。
- 失败任务不会错误扣费。
- 租户隔离无已知漏洞。
- 内容安全和投诉入口可用。
- 所有生成任务有审计记录。
