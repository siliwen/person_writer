# 写作 Agent 工作流

## 总体流程

```text
需求输入
  ↓
需求解析与风险检查
  ↓
检索个人风格素材
  ↓
生成大纲或创作计划
  ↓
用户确认或调整
  ↓
分段/分章生成初稿
  ↓
风格一致性审校
  ↓
事实、结构、合规检查
  ↓
重写或定稿
  ↓
保存版本与计费结算
```

## 任务状态

| 状态 | 含义 |
|---|---|
| `created` | 用户已创建任务，尚未开始 |
| `quoted` | 已完成额度预估 |
| `reserved` | 已冻结额度 |
| `input_moderating` | 正在审核输入 |
| `planning` | 正在生成大纲或创作计划 |
| `awaiting_user_confirmation` | 等待用户确认大纲 |
| `retrieving_style` | 正在检索风格素材 |
| `drafting` | 正在生成初稿 |
| `reviewing` | 正在风格和质量审校 |
| `output_moderating` | 正在审核输出 |
| `completed` | 已完成并结算 |
| `blocked` | 被安全、额度或用户确认阻断 |
| `failed` | 系统失败，需释放或部分结算 |

## Prompt 分层

### 系统层

定义产品边界、内容安全、版权边界、不得泄露素材、不得伪造用户授权等硬规则。

### 文体层

按文章、小说、散文、诗歌分别定义：

- 结构要求。
- 节奏要求。
- 输出格式。
- 常见失败模式。
- 审校标准。
- AI 套话和模板化表达的负向约束。

### 个人风格层

由风格档案生成，包含：

- 语气和叙述距离。
- 句长和节奏。
- 常用修辞和意象。
- 结构偏好。
- 禁用表达。
- 代表片段摘要。

### 任务层

来自用户本次输入，包含主题、字数、目标读者、必须包含、必须避免、输出格式。

## 四类文体策略

| 文体 | 生成策略 |
|---|---|
| 文章 | 先确定观点、结构、论证材料，再生成正文 |
| 散文 | 先确定情绪线、意象组、叙述视角，再生成 |
| 诗歌 | 先确定意象、节奏、形式限制，再生成多个候选 |
| 小说 | 先维护人物、冲突、场景、章节目标，再分章生成 |

小说增强能力包括多角色对话生成和人物语气一致性检查；散文增强能力包括意象发散和情感基调迁移；诗歌增强能力包括韵脚建议、断句节奏和格律检查。

## 风格审校

风格审校不只问“像不像”，应拆成可执行检查：

- 是否符合用户常用语气。
- 句子长度和节奏是否接近。
- 意象、比喻和词汇是否过度模板化。
- 是否出现用户明确禁用表达。
- 是否为了模仿而牺牲任务要求。
- 是否混入第三方作者或平台爆款风格。
- 是否出现平台级或用户级禁用的 AI 套话。

审校结果应形成结构化 JSON，供重写步骤使用。
