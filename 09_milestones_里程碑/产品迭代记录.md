## 2026-08-15 · 无风格写作收尾 + 未登录体验

**需求来源**：用户截图反馈 + 两项确认（①全后台括号说明一起去掉；②风格库未登录也显示界面，文章库保持现状不动）。

### 改动点
1. **后台说明文字清理**
   - 移除 `AdminConfig`「会员与配置（均入库，代码不写死）」括号说明，仅保留「会员与配置」。
   - 移除 `AdminUsers` 操作原因下的「（本次积分 / 等级调整共用，会记入审计日志）」括号提示。
   - 保留功能性 UX 提示（如「可多选」「可选」「全站」），仅去除实现说明类括号文案。

2. **未登录也显示系统界面（点扣费按钮弹登录）**
   - `DashboardView` 未登录分支不再显示「还没有登录」空状态，改为直接渲染 `FreeWriteBox`（系统写作框），并在下方加一条访客提示。
   - 访客点击「生成文章」扣费按钮时，`FreeWriteBox.handleGenerate` 先 `requireAuth()` 弹出登录框，登录后再生成。
   - `StylesView`（风格库）未登录本就显示界面，其「开始写作」同样 `requireAuth()` 弹登录，保持不变。
   - `ArticlesView`（文章库）未登录仍显示「请先登录」占位，按用户要求保持现状不动。

3. **退出登录回首页（非风格库）**
   - `WritingWorkspace` 退出登录的 auth 状态清理中，将跳转视图由 `styles` 改为 `dashboard`（首页）。

### 涉及文件
- `apps/web/components/AdminConfig.tsx`
- `apps/web/components/AdminUsers.tsx`
- `apps/web/components/DashboardView.tsx`
- `apps/web/components/WritingWorkspace.tsx`（logout 清理逻辑）
- `apps/web/app/globals.css`（新增 `.dashboard-guest-hint` 样式）
- `apps/web/components/FreeWriteBox.tsx`（既有 `requireAuth()` 逻辑，未改）

### 验证
- `tsc --noEmit` 通过；`next build --webpack`（清空 NODE_OPTIONS）通过。
- 未登录访问首页可见写作框；点「生成文章」弹登录；风格库可见、文章库仍占位；退出登录回到首页。

## 2026-08-16 · 全部 system prompt 后台可配置（提示词模板）

**需求来源**：用户确认「所有提示词都改成后台可配置的」，并明确**不要「新建模板 / 版本管理 / 删除 / 设为启用」**，改为每个用途一条固定可编辑模板（列表 + 编辑弹窗 + 重置默认）。

### 改动点
1. **用途常量集中**（`app/core/constants.py`）
   - 新增 `PURPOSE_STYLE_ANALYSIS / STYLE_WRITING / FREE_WRITING / ARTICLE_EVALUATION / REVISE` 与 `ALL_PURPOSES`、`PURPOSE_LABELS`（用途→中文名）。

2. **默认提示词集中 + seed + 重置**（`app/core/prompt_template_service.py`）
   - 抽出 `DEFAULT_STYLE_ANALYSIS_PROMPT / STYLE_WRITING_PROMPT / ARTICLE_EVALUATION_PROMPT / REVISE_PROMPT`（已有 `DEFAULT_OPTIMIZE_PROMPT` / `DEFAULT_FREE_WRITE_PROMPT`）。
   - `ensure_default_optimize_template` 升级为 `ensure_default_prompt_templates`：启动时为全部 6 用途各 seed 一条启用模板。
   - 新增 `reset_admin_prompt_template`：将某模板 system_prompt 重置为代码内置默认。

3. **4 个调用点改读后台模板（无则兜底默认）**
   - `style_profile_builder.build_style_profile_v2` 增加 `db` 参数，取 `style_analysis` 模板。
   - `prompt_composer.compose_prompt / compose_free_prompt` 增加 `system_prompt` 可选参数，默认回退内置常量。
   - `mvp_service.create_writing / create_free_writing / revise_document` 分别取 `style_writing / free_writing / revise` 模板。
   - `evaluation_service._build_judge_messages / evaluate_document` 取 `article_evaluation` 模板。

4. **后台接口精简**（`app/admin_routes.py`）
   - `GET /v1/admin/prompt-templates` 返回全部 6 条（不再只 optimize_prompt）。
   - `PATCH` 仅接受 `system_prompt`（name/purpose/is_active 锁定）。
   - 移除 create / delete / set-active 端点；新增 `POST /v1/admin/prompt-templates/{id}/reset` 重置默认。

5. **前端提示词模板页**（`apps/web/components/AdminPromptTemplates.tsx`）
   - 由空状态改为「6 行列表 + 行内编辑弹窗（只读用途/名称，编辑 system_prompt）+ 重置默认」。
   - `lib/api.ts` 新增 `resetAdminPromptTemplate`。
   - `globals.css` 新增列表/弹窗/只读框样式（纸墨主题）。

### 涉及文件
- 后端：`app/core/constants.py`、`app/core/prompt_template_service.py`、`app/core/style_profile_builder.py`、`app/core/prompt_composer.py`、`app/core/mvp_service.py`、`app/core/evaluation_service.py`、`app/database.py`（seed 调用）、`app/admin_routes.py`
- 前端：`apps/web/components/AdminPromptTemplates.tsx`、`apps/web/lib/api.ts`、`apps/web/app/globals.css`
- 测试：`apps/api/tests/test_prompt_templates.py`（新增）、`tests/test_free_write.py`（改写原 CRUD 测试为 list+edit+reset）
