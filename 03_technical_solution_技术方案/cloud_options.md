# 云方案对比

## 首选：阿里云方案

适用条件：主要用户在中国大陆，收款主体和服务器也在中国大陆。

推荐组合：

- 模型：阿里云百炼/Qwen。
- 计算：函数计算 FC 起步，后续评估 ACK 或 ECS。
- 数据：RDS PostgreSQL + pgvector。
- 存储：OSS 私有 Bucket。
- 网络：CDN + WAF + HTTPS。
- 安全：内容安全文本审核、应用层限流、审计日志。
- 支付：支付宝、微信支付，自建订单和额度账本。

优势：

- 国内访问链路更稳定。
- 云产品组合完整。
- ICP、域名、WAF、内容安全、对象存储在同一云上落地更简单。
- Qwen 中文能力强，适合作为首轮盲测对象。

主要风险：

- 具体模型能力需要用真实个人风格素材盲测，不应只看厂商榜单。
- 模型计费和上下文长度会变化，必须配置化。
- 百炼工作流不能替代业务状态机。

## 备选：火山引擎

适用条件：希望更快试 Doubao 等国内模型，或团队已有火山资源。

优势：

- 模型选择灵活。
- 内容业务团队可能更熟悉。

取舍：

- 仍需自建账号、订单、额度、风格档案和写作状态机。
- 需要和 Qwen 做同一评测集盲测。

## 备选：腾讯云

适用条件：强依赖微信生态、小程序和腾讯云资源。

优势：

- 微信支付、小程序、腾讯云生态协同更顺。
- 混元和向量数据库可纳入测试。

取舍：

- 技术路线与阿里云类似，核心仍是自研 SaaS 层。
- 模型效果必须以真实中文写作样本评测。

## 海外方案

如果后续明确服务海外用户，可评估：

- Vercel + Supabase/Neon + OpenAI/Claude/Gemini。
- AWS Bedrock + Aurora pgvector/OpenSearch + S3 + CloudFront。

但中国大陆首发不建议把海外链路作为主方案，原因是访问稳定性、支付、合规和数据地域都会增加复杂度。
