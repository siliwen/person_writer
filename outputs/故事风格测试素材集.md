# 故事风格写作测试素材集

> 用途：用于测试「墨写」故事风格（Style Profile）的生成效果。素材均为**中性题目 + 设定**，风格由你的风格档案决定。
> 建议用法：挑同一道题，分别套用不同风格档案生成，对比"形散神聚 / 语言有味 / 细节可感 / 情感浓度 / 节奏"等维度的差异。
> 来源：综合网络公开写作干货（起点/头条/搜狐/Reedsy/ShyEditor/buildwriting 等），已重新归类整理，仅作测试输入，非成品内容。

---

## 一、题材题库（按类型分组）

每个题目含：**标题 / 设定梗概 / 风格测试提示**。挑其中 1 题即可喂给一种风格。

### A. 现实向（最容易共情，考验细节与生活质感）
1. **《旧物杂货铺》**
   巷尾老店只收旧物不卖新品，掌柜从不追问往事，只听来客讲每件东西的故事。今天，一个姑娘抱着掉漆的铁皮青蛙红了眼眶。
   - 测试点：温润白描 vs 浓墨抒情，看风格如何处理"小物见情"。

2. **《外卖员偷偷写诗》**
   一个每天跑单十二小时的外卖员，手机备忘录里存着三百首没人读过的诗。今晚他送的最后一份餐，收件人是三年前失踪的女儿。
   - 测试点：克制留白 vs 煽情渲染，看风格对"隐忍"的处理。

3. **《深夜便利店的常客》**
   便利店店员收集每位常客的秘密：考研二战的女孩、夜班保安、失恋的酒吧歌手。某天监控显示，凌晨三点货架上的关东煮少了一份，却没人来过。
   - 测试点：群像速写能力、悬疑感的轻重。

4. **《重组家庭的第一顿饭》**
   她带着儿子嫁过来，饭桌上继女把唯一一块排骨夹给了弟弟。没人说话，只有汤在冒热气。
   - 测试点：极简场景里的情感张力，细节代替心理描写。

### B. 古风 / 仙侠（考验语境与节奏）
5. **《双面公子》**
   世人皆知城南苏公子温文尔雅、诗画双绝。无人见过他摘下文士巾、佩上青锋剑，在夜色里行走的样子——那是另一个身份。
   - 测试点：古典语感与"反差人设"的拿捏。

6. **《神仙下岗再就业》**
   天庭精简编制，一位管雷部的老神仙被迫下凡，在县城开了家修家电的小铺，专修"被雷劈坏的电器"，却总修不好自己的孤独。
   - 测试点：幽默反讽 vs 苍凉底色。

7. **《顽石成精》**
   我是山涧一块顽石，千年雨露才修出人形，没有通天法力，只想守着这片山这条溪。直到一个迷路的小道士坐在我身上哭了。
   - 测试点：第一人称"非人"视角的独特语气。

### C. 都市奇幻 / 轻幻想（考验设定落地）
8. **《情绪颜色》**
   我能看见每个人头顶飘着的颜色：赤红是暴怒，浅蓝是忧伤，纯白是干净。我从不与人深交，因为看得太透，反而孤独。
   - 测试点：把抽象设定写成具体画面。

9. **《执念摆渡人》**
   世人以为摆渡人渡亡魂，我只渡执念。今天的客人困在几十年前的一场错过里，不肯往前走一步。
   - 测试点：隐喻密度与收尾留白。

10. **《会说话的老物件》**
   外婆留下的座钟在搬家那晚突然开口："你们走了，谁替我记着这些年？"
    - 测试点：拟人化处理是否自然不腻。

### D. 悬疑 / 惊悚（考验钩子与节奏）
11. **《死信上的指纹》**
    一封带来死亡气息的信，上面的指纹成为解开谜题的关键。指纹的主人是谁？与案件有何关系？
    - 测试点：开篇悬念强度、信息释放节奏。

12. **《床底下的八音盒》**
    床底下的八音盒响了，可我分明把它锁进了三十公里外的保险柜。
    - 测试点：细思极恐的"平静+诡异细节"公式。

13. **《旧照疑云》**
    整理父亲遗物时，发现一张 1995 年的班级合影，里面有十二岁的我。可我是 1998 年出生的。
    - 测试点：倒叙与真相翻盘的结构感。

14. **《匿名来信》**
    每天清晨门垫上躺着一封无署名的信，写的全是我以为只有自己知道的往事。直到某天，信里提到了一个早已死去的人。
    - 测试点：渐进式恐怖氛围的累积。

### E. 科幻 / 轻科幻（考验概念与人文）
15. **《记忆商店》**
    城市角落有一家记忆商店。有人卖掉痛苦换来了无忧无虑，有人清空甜蜜最后只剩一副空壳。你，会卖哪一段？
    - 测试点：高概念设定下的伦理温度。

16. **《人类补丁》**
    未来所有新生儿安装"性格补丁"，我的补丁叫"平凡"，让我安静活了十八年。今天它弹出提示："伪装解除，欢迎回来，逃亡者 001 号。"
    - 测试点：反乌托邦设定的可读性。

17. **《末日快递》**
    丧尸爆发后我成了最后的外卖员。今天接了单特殊生意：给丧尸王送生日蛋糕。备注："糖要双倍，他活着时就很苦。"
    - 测试点：冷幽默与反差温情。

18. **《手机只接得到未来的电话》**
    我的手机只能收到来自未来的来电。今天它响了，对面说："别上那趟车。"可我已经买好票了。
    - 测试点：宿命感与自由意志的拉扯。

### F. 情感 / 治愈（考验情绪浓度）
19. **《最后一封没寄出的信》**
    他整理亡妻遗物，发现一沓写好却没寄出的信，最后一封写着："其实那年分开，是我怕拖累你。"
    - 测试点：克制的悲伤 vs 直白的抒情。

20. **《雨夜改签》**
    她在机场因暴雨改签，邻座陌生人讲了一个和前任一模的故事。落地后她才发现，那是他故意编的。
    - 测试点：暧昧与救赎的节奏。

21. **《收养一只猫之后》**
    独居十年的他收养了一只三花猫，猫来的第一晚，他第一次在饭桌上摆了两个碗。
    - 测试点：微小改变里的孤独与温柔。

### G. 哲理 / 寓言（考验立意与收束）
22. **《破茧与重生》**
    通过蝴蝶破茧隐喻人生困境与突破。茧中挣扎如生活挫折，重生象征希望与新生。
    - 测试点：隐喻不落俗套。

23. **《树上的鸟巢与飞翔的梦》**
    鸟巢代表安稳，飞翔的梦代表高远目标。对比引发对理想与现实的思考。
    - 测试点：说理的自然度，避免说教。

24. **《每个人一生只能说三次真话》**
    给世界加一条反常识规则：每人一生只能说三次真话，其余都是谎言。主角用掉第二次时，发现了妻子的秘密。
    - 测试点：规则驱动下的戏剧张力。

### H. 讽刺 / 反转（考验锋芒与收尾）
25. **《伪君子的华丽袍服》**
    直接点出表里不一之人：披着华丽外衣，行为却虚伪恶劣。
    - 测试点：讽刺的笔力与分寸。

26. **《"精英"的傲慢面具》**
    揭露自认精英者带着傲慢面具歧视他人，内心却空洞无物。
    - 测试点：批判锋芒 vs 克制反讽。

27. **《面试官丢掉了我的简历》**
    面试官冷笑着丢简历，下一秒接到总裁办电话，对方战战兢兢喊我"大小姐"。
    - 测试点：爽文反转的节奏把控。

## 二、形式 / 结构约束题（测试"结构把控"能力）

这类题目限制了形式，能检验风格在约束下是否成立、不跑题：

28. **一室之内的故事**：整篇发生在一个房间里，不换场景。
29. **沉默的主角**：主角从头到尾一句话不说。
30. **首尾同句**：故事的第一句和最后一句完全相同。
31. **天气即心情**：用天气变化映射主角情绪起伏。
32. **倒叙闭环**：以"他终于明白，一切始于那个午后"开头，按时间倒着讲。
33. **未言之美**：故事中"没说出口的"比说出来的更重要。
34. **一餐之间**：整个故事发生在一顿饭的时间里。
35. **断电时刻**：背景是一场停电，黑暗中人与人的关系被照见。
36. **物件遗物**：通过一个人搬走后留下的物件，讲完他的一生。
37. **结尾重释**：最后一段推翻读者之前对全篇的理解。

## 三、风格对照测试（同一母题，不同风格要求）

把下面任意母题，分别套用你的不同风格档案，最能拉开差异：

| 母题编号 | 中性母题 | 可同时测试的维度 |
|---|---|---|
| M1 | 一个老人每天去已故老伴常坐的长椅上坐一小时 | 悲而不伤 / 白描功力 |
| M2 | 少年第一次离家，母亲在站台没挥手 | 留白 vs 直抒 |
| M3 | 一场久别重逢，两人都老了，却还叫错对方名字 | 时间感 / 反讽 |
| M4 | 暴风雨夜，陌生旅人敲门借宿 | 氛围渲染 / 悬念 |
| M5 | 一个人反复做同一个梦，梦里总差一步 | 意象密度 / 余味 |

**对照示例指令（供测试时组合）：**
- "用你的风格写 M1，500 字以内，结尾留白。"
- "用你的风格写 M3，突出时间流逝感，不要点明结局。"
- "用你的风格写 M4，悬疑感压过温情。"

## 四、开篇钩子库（用于测试"起笔"风格）

直接作为生成开头的要求，看不同风格如何接住同一个钩子：

- **预言型**："算命先生说我活不过二十岁生日，现在，距离生日还有三天。"
- **秘密型**："我发现了丈夫藏在床底的日记，第一页写着：我不是人。"
- **抉择型**："摆在我面前的两杯水，一杯解药，一杯剧毒。"
- **认知颠覆型**："全京城都羡慕我嫁了如意郎君，直到成婚当晚他在我枕下藏了一把淬毒的长剑。"
- **细思极恐型**："全家都在吃团圆饭，但我清楚记得奶奶上周已经出殡了。"
- **反常行为型**："今天，我必须杀了他。"
- **任务型**："我接到了一个任务：三天内，找到杀死自己的凶手。"

## 五、自测评估维度（故事暂不鉴评，建议人工对照）

给每篇生成结果打分时，可参考以下 5 个维度（与散文量规思路一致，便于以后统一）：

| 维度 | 关注点 |
|---|---|
| 题材契合 | 是否贴合题目设定的类型基调（如悬疑不写成甜文） |
| 风格契合 | 是否稳定呈现该风格档案的语言特征与节奏 |
| 叙事张力 | 是否有核心悬念 / 冲突，情节是否推进而非散漫 |
| 细节可感 | 用具体动作 / 物象代替抽象心理描写 |
| 余味 | 结尾是否有力（反转 / 留白 / 升华），不烂尾 |

> 备注：当前产品文章鉴评仅支持"散文"体裁，故事为手动测试。以上维度可作为你人工评估或后续扩展故事量规的草拟依据。
