# 开工前需要明确的事项

## 结论

MVP 方案已经确定后，正式开工前不需要继续泛泛讨论“大模型怎么选”。现在最重要的是把会影响数据库、接口、成本、验收和合规的事项定死。

## 必须明确

### 1. 首发客户形态

需要明确第一版到底服务谁：

- 个人写作者 SaaS。
- 作家协会定制 PoC。
- 面向作协和个人用户都可用的平台。

已确定：MVP 是个人写作 SaaS 平台。作家协会只是 Organization/Tenant 场景，组织可开设权限并在组织下创建个人账户；具体使用者仍是个人 User/Writer。

### 2. MVP 文体范围

需要明确首发到底做几类文体。

建议：

- 必做：文章、散文、诗歌、小说章节。
- 小说首版只做“章节级生成/续写”，不做完整长篇自动生成。
- 格律检查、多角色对话、人物关系网、名家风格库放到增强版。

### 3. 风格素材最低要求

需要明确用户上传多少素材才能创建可用 Style Profile。

建议：

- 3-5 篇代表作可启动诊断。
- 正式推荐 8000 字以上。
- 不同文体优先分开建档。
- 用户必须确认素材权利和训练授权选项。

### 4. RAG MVP 验收标准

需要明确什么叫“RAG 有用”。

建议：

- `Style Profile + RAG` 在盲测中优于普通模型直出。
- 检索只返回当前 Tenant 和当前 Style Profile 的片段。
- 删除素材后不再召回。
- 每次生成能记录使用了哪些片段。
- 召回片段不导致大段照抄原文。

### 5. 模型供应商与首测模型

需要明确第一轮盲测的模型池。

建议：

- 主线：阿里云百炼/Qwen。
- 对照：火山 Doubao、腾讯混元或其他一个强中文模型。
- 所有模型 ID、价格、上下文长度、超时和回退顺序配置化。

### 6. 计费单位

需要明确用户到底买什么。

建议：

- 不做无限生成。
- 使用套餐 + 额度。
- 写作任务先预估并冻结额度，成功后按实际用量或规则结算，失败释放。
- 后台必须记录 token、模型、重试、审核和毛利。

### 7. 支付和主体

需要明确首发是否真实收款。

已确定：MVP 不真实收费，但需要做 Virtual Credit 和 Credit Ledger。真实支付、套餐定价、退款和发票后续再设计。

后续收费阶段需要定：

- 收款主体。
- 支付宝、微信支付是否都接。
- 是否需要发票。
- 退款规则。
- 是否先做测试支付再上线真实支付。

### 8. 部署区域和合规路线

需要明确是否面向中国大陆公网。

如果面向大陆公网，需要提前处理：

- 域名和 ICP。
- HTTPS。
- WAF。
- 内容安全审核。
- AI 内容标识。
- 隐私政策、用户协议、版权投诉。

### 9. 数据删除和授权

需要明确用户数据的处理规则。

建议：

- 已确定：用户素材默认私有。
- 已确定：默认不用于训练。
- 删除 Material 时，Segment、向量、缓存和后续检索资格都要处理。
- 后续 Personal LoRA 单独训练、单独授权、单独收费；训练授权必须单独勾选，不能藏在通用协议里。

### 10. 第一轮评测集

需要先准备评测集，再开始大规模开发。

建议：

- 30-50 个任务。
- 覆盖文章、散文、诗歌、小说章节。
- 每个任务有用户素材、任务要求、人工评分表。
- 对比普通直出、Prompt 版、Style Profile + RAG 版。

## 可以边做边明确

- UI 视觉风格。
- 具体套餐价格。
- 是否接小程序。
- 是否做 Word 导出美化。
- 是否支持团队协作。
- 是否做运营后台复杂权限。

## 暂时不要投入

- 私有 GPU 推理。
- 每个用户独立微调。
- LangChain/LlamaIndex 生产编排。
- Milvus/Qdrant 独立向量库。
- 名家风格库。
- 创作社区。
- 完整长篇小说自动生成。

## 开工前最小决策包

正式进入开发前，至少要确认：

1. 首发是个人 SaaS 还是作协 PoC。
2. MVP 是否真实收费。
3. 第一轮模型盲测名单。
4. 风格素材最低要求。
5. 30-50 个评测任务怎么准备。
6. 账号、Tenant、Writer 三者关系。
7. 额度计费规则。
8. 数据删除和训练授权规则。
9. 部署在阿里云大陆还是先本地/测试环境。
10. 谁负责内容、产品、技术、合规四块验收。

当前已明确：1、2、8 的主结论已确定；5 的评测集方案见 `D:\AI_talk\personal_writing_agent_saas\06_testing_测试方案\mvp_eval_set_design.md`。
