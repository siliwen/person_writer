# 项目章程

## 项目目标

搭建一个可公网运营、可收费的个人风格写作 Agent。用户提供自己的文章或其他授权素材后，系统能提取并维护其个人写作风格，在不同文体下生成相应作品，包括文章、小说、散文、诗歌，并支持改写、审校、版本管理和导出。

对外产品表达建议采用“个人风格创作助手”或“灵感副驾驶”，避免宣传为替代人类创作的“代笔机器”。系统负责初稿、扩写、润色、风格迁移和机械性整理；用户始终掌握立意、情感表达和最终定稿权。

## 核心判断

第一版不要把重点放在“训练一个属于每个用户的模型”。更稳的路线是：

1. 用户上传授权素材。
2. 系统解析素材，抽取结构化风格档案。
3. 将代表段落写入向量库，并按租户隔离。
4. 写作时检索少量相关片段，结合风格档案和任务要求生成。
5. 保存用户修改稿和评分，用于后续个性化优化。

只有当积累到足够高质量、明确授权的“生成稿到用户修改稿”数据后，才评估微调、LoRA 或专属模型。

## 非目标

- 不使用 Dify 作为生产核心编排。
- 不在 MVP 阶段自建 GPU 推理集群。
- 不承诺完全复刻任何第三方在世作者风格。
- 不默认把用户上传作品用于公共模型训练。
- 不把阿里云百炼、火山方舟等模型平台当作账号、订单、额度、版本和租户数据的主系统。

## 首发假设

- 用户主要在中国大陆。
- 支付主要通过支付宝和微信支付。
- 模型首选阿里云百炼/Qwen，但代码结构必须支持后续接入火山方舟、腾讯混元、OpenAI、Claude 等。
- 首发先做 Web 端，后续再考虑小程序。
- 产品采用额度制或套餐加额度制，不做无限生成套餐。

## 成功标准

- 用户能上传 5～20 篇个人素材并生成可编辑的风格档案。
- 新用户可用 3～5 篇代表作启动风格诊断，但正式档案建议达到 8000 字以上。
- 在盲测中，个人风格版本明显优于通用模型直接生成。
- 文章、散文、诗歌可以一次生成；小说支持章节级异步生成。
- 每次生成可追踪模型、素材、Prompt、成本和版本。
- 用户可以删除、导出自己的素材和作品。
- 收费闭环支持额度冻结、成功结算、失败释放。
